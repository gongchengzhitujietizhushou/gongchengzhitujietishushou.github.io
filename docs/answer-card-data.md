# 答案卡（Answer Card）数据说明

工程制图解题助手按**视图构造任务**组织题型（category）。每个题型对应一个独立的答案卡模块 `js/acard_xxx.js`，由一段输入 JSON 驱动渲染。LLM 返回 `{ mode: "card", category, data, ... }` 时，前端会用 `data` 填充对应题型的答案卡。

## 分类总览

| category | 任务 | 答案卡模块 | 答案图高亮视图 |
| --- | --- | --- | --- |
| `top_view` | 求作俯视图 | `js/acard_top_view.js` | 俯视图（黑、加粗） |
| `left_view` | 求作左视图 | `js/acard_left_view.js` | 左视图（黑、加粗） |
| `front_view` | 求作主视图 | `js/acard_front_view.js` | 主视图（黑、加粗） |

三个题型共用同一个立体（轴线水平的圆柱，开有前后贯通的楔形孔），由共享构建器 `js/acard_solid.js` 渲染 3D 场景 + 三视图答案。区别仅在于"所求"是哪一个视图，由 `Render.render(..., { answerView })` 的高亮决定。

> 旧历史记录中的 `cylinder_wedge_hole` 会自动映射为 `top_view`（求作俯视图）。

## 输入 JSON（三个题型共用）

```json
{ "R": 50, "L": 130, "X1": 20, "X2": 104, "A": 40 }
```

| 字段 | 含义 | 约束 |
| --- | --- | --- |
| `R` | 圆柱半径 | `R > 0` |
| `L` | 圆柱长度 | `L > 0` |
| `X1` | 楔形孔尖点（三角形顶点）距左端距离 | `0 ≤ X1 < X2` |
| `X2` | 楔形孔底平面距左端距离 | `X1 < X2 ≤ L` |
| `A` | 楔形孔口半高 | `0 < A < R` |

- 单位任意，但需**同比例**（建议令 `R = 100`，便于比较）。
- 所有字段均为数值（number），缺失或非法时 `normalize()` 返回 `null`，卡片显示"数据无效"。
- 立体参数描述：主视图为矩形 `L × 2R` 内一个三角形孔口；左视图为半径 `R` 的圆内两条水平虚线弦（对应孔口与孔底）；圆柱上开有前后贯通的楔形孔。

## 各题型明细

### `top_view` — 求作俯视图

- **描述**：轴线水平的圆柱，主视图为矩形内一个三角形孔口，左视图为圆内两条水平虚线弦；圆柱上开有前后贯通的楔形孔，求作俯视图。
- **答案图**：俯视图高亮为所求（黑、加粗），主视图、左视图为已知（灰蓝）。

### `left_view` — 求作左视图

- **描述**：轴线水平的圆柱，主视图为矩形内一个三角形孔口，俯视图反映孔口与孔底的投影关系；圆柱上开有前后贯通的楔形孔，求作左视图。
- **答案图**：左视图高亮为所求（黑、加粗），主视图、俯视图为已知（灰蓝）。

### `front_view` — 求作主视图

- **描述**：轴线水平的圆柱，左视图为圆内两条水平虚线弦，俯视图反映孔口与孔底的投影关系；圆柱上开有前后贯通的楔形孔，求作主视图。
- **答案图**：主视图高亮为所求（黑、加粗），左视图、俯视图为已知（灰蓝）。

## 完整 LLM 卡片返回示例

```json
{
  "mode": "card",
  "category": "top_view",
  "title": "求作俯视图",
  "confidence": 0.9,
  "data": { "R": 50, "L": 130, "X1": 20, "X2": 104, "A": 40 },
  "analysis": "1. 圆柱轴线水平，主视图为矩形，左视图为圆。\n2. 楔形孔前后贯通……",
  "notes": ["注意孔口三角形与孔底平面的投影关系。"]
}
```

- `mode` 固定为 `"card"`（纯文字时为 `"text"`）。
- `category` 必须取自上表；否则前端会降级为文字说明。
- `data` 字段按上文输入 JSON 校验，非法时降级为文字说明。
- `analysis` / `notes` 可选，用于展示解题过程与备注。

## 如何新增一个题型

1. 新建 `js/acard_<category>.js`，调用 `AnswerCards.register('<category>', { title, description, dataSchema, normalize, mount })`。
2. 在 `index.html` 中按顺序引入该脚本（放在 `js/acards.js` 之后、`js/llm.js` 之前）。
3. `normalize(data)` 校验并规范化输入 JSON，非法返回 `null`。
4. `mount(host, data, meta)` 渲染答案卡，返回 `{ destroy() }` 用于卸载。
5. 可复用共享构建器（如 `js/acard_solid.js` 的 `ACardSolid.mountSolidCard`）。
6. 在本文档中补充分类条目。
